    How these numbers are counted

    Page views
    Each page load recorded in the range (duplicates within 30 seconds are dropped).
    Daily visitors
    Distinct visitor markers for one UTC day. The marker changes every day.
    Daily visitors, summed
    Daily visitor counts added together across the range. One person on two days is counted twice. This is not a unique-visitor figure.
    Unique visitors
    Not reported. Markers change daily, so they cannot be merged across days.
    Sessions
    Not reported. No session identifier is stored.
    Peak day
    The UTC day with the most page views in the range.

    Not measured

    Countries and cities

    Not collected. This setup does not receive a visitor country, so no map is shown.

    Returning visitors

    Not measured. Without cookies, visits cannot be linked across days.

    Session length and bounce rate

    Not measured. Only page loads are counted, not time on page.
